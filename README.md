# Booki

Projet réalisé dans le cadre de ma formation Développeur Web chez OpenClassrooms.

## Objectif

Intégrer une interface de réservation d'hébergements à partir d'une maquette responsive.

## Technologies utilisées

- HTML5
- CSS3

## Fonctionnalités

- Affichage des hébergements
- Affichage des activités
- Filtres visuels
- Interface responsive
